# Orbit frontend prototype

Open `index.html` in a browser. It is standalone HTML, CSS and JavaScript, with no installation, external fonts, CDN scripts or Canva runtime dependencies.

The supplied Canva export was a color accessibility simulator. This replacement implements the learning assistant brief in the same single-file format. It does not edit a Canva design or create presentation slides. The three screens are Chat (default), Dashboard, and Practice, with distinct layouts and a shared sidebar.

## Included interactions

- Chat suggestions, course context selector, new conversation, loading state, authored demo replies and source disclosures. The context selector is a frontend control reserved for future API integration; it does not change the authored demo answers.
- Dashboard with sample scores, progress bars, assessment history and a shortcut into normalization practice.
- Practice course/topic, difficulty, question count and mode selection. Three courses each contain five foundation and five intermediate authored questions. Each demo course currently has one topic.
- Answer selection, question navigation, answer checking in learning mode, submission, scoring, explanations and session reset. Exam explanations appear after submission.
- Responsive layout, labeled controls, keyboard focus indicators and reduced-motion support.

## Integration boundary

All student information is fictional demo data; chat uses a small local response matcher, not an LLM. Questions are selected from an authored bank, not generated by RAG. No database, authentication, eligibility service or persistence is connected. No data leaves the page.

Replace the chat response handler with your authenticated backend endpoint; send the selected course context and conversation messages. Load dashboard values from controlled student-data services. Replace the practice bank selection with a backend endpoint that retrieves course content and returns validated questions with real source references. Eligibility must come from the deterministic backend service. Do not put API credentials in this file.

## Canva

The HTML is the code deliverable for adapting your Canva Code project. Canva's injected `/_sdk/` and bootstrap scripts from the export are intentionally omitted because they belong to Canva's hosting environment. Direct Canva import/paste compatibility has not been verified. If separate slides are needed, use each of the three screen layouts as a separate presentation page; this file itself is an interactive app, not a slide deck.
