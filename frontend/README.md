# Orbit

AI-Powered College Learning Assistant

Open index.html directly in a browser. No installation or external assets are needed.

## Interface

Chat opens by default with a collapsible left sidebar, neutral light surfaces, restrained teal accents, and keyboard-accessible controls. The sidebar includes a profile footer and becomes a dismissible drawer on mobile. Dashboard shows illustrative course progress, assessment history, summary metrics, and a practice shortcut. Practice offers built-in general study exercises with course, difficulty, count, learning/exam modes, scoring and explanations.

## Current integration status

Chat is not connected to an AI service and explicitly reports that submitted questions have not been sent. Dashboard figures and the profile identity are fictional, user-requested display data, identified in the dashboard and profile details. Built-in exercises are independent of college records. Practice state lasts for the current page session only. The two CSV files are awaiting the user's analysis; this interface change does not read or modify them.

After dataset analysis, connect chat and dashboard to backend services and replace or extend the built-in exercises with grounded course content. Keep credentials and eligibility rules on the server.
